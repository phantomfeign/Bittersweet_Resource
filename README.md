Bittersweet Supplement is a Minecraft datapack project focused on slowing down progression while giving some unknown or obscure mechanics and items more uses and time in the spotlight. It also aims to reward exploration and remove the need for redstone farms and mob grinders.  

_All code and art is by me. I am anti-AI and will NEVER promote its use._

# Major Changes
* **Enchanting & repairing have been completely reworked**, with 20+ new enchantments being added, mainly obtained from Requiems, a new form of enchanted book.
* **Hunger & potions been removed**: food heals you directly and can grant buffs. Some potions can be crafted now.
* **Furnaces have been reworked**: the campfire and blast furnace are now required for progression.
* **Progression is slowed down** with reworked tiers, armor set bonuses, and new sidegrades.
* **Death is more punishing**, temporarily costing you max health.
* **Villagers are gone**. Though, I hear the wandering trader's still kicking.
* **3 New Materials**: Bronze, Rose Gold, and Verdum.

I don't want to write an essay about this project, and most people don't want to read it. If you're really curious, look through the files. :)

# Installation
How to install:
1. Download both the datapack and the resourcepack. **DO NOT** unzip the files.
2. New World: More → Datapacks → Open Pack Folder → drop the datapack.zip in and move it to Selected.
3. Resource Pack: Options → Resource Packs → Open Pack Folder → drop the resourcepack.zip in and move it to Selected.

**Putting this datapack inside a pre-existing world may break it.** 
This is because some item ids have been used for different purposes. I also added worldgen changes. Be cautious!

# Some Tips
* Take your time. If you hop into a cave with little food or armor, _you will die_. 
* Give Gold a real shot. I really wanted to give it a fighting chance. Plus, you need it to progress.
* Mine the spawners in the dungeons. Spawners work differently now and drop something you'll definitely want.
* Don't sleep too many nights in a row. Trust me.
